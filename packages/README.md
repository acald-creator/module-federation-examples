# Packages Directory

This directory contains shared packages and utilities used across Module Federation examples.

## Future Packages

Planned shared packages include:
- `@mf-examples/performance-monitor` - Performance monitoring utilities for Module Federation
- `@mf-examples/shared-types` - Common TypeScript types and interfaces
- `@mf-examples/test-utils` - Testing utilities for federated modules
- `@mf-examples/build-tools` - Build and bundling utilities

Each package should follow the monorepo conventions and be publishable independently.
